# v0.5.4

## Highlights

- `expose --to` and `unexpose --to` now take a peer's name as well as its key, the same as `forget`, `project` and `unproject`. For example, `pai-sho expose --to chunker 2099`. The name is the one `pai-sho list` shows. If two peers have the same name, the command fails with an error. In that case, pass the peer's key to `--to`.
