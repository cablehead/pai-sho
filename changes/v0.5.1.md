# v0.5.1

## Highlights

- Forwarding no longer waits for a TCP ACK between chunks. On `--tun`, that wait sat an SSE event mid-frame (`data: ...` then `\n\n`) until the peer ACKed, so EventSource would not dispatch. Loopback was never affected. Compatible with 0.5.0 daemons; upgrade the `--tun` side to get the fix.
- A `warn` log when a tunnel write blocks for 10ms or more (TUN buffer or QUIC window full).
- TUN TCP buffers are 256 KiB, up from 8 KiB, so a large Datastar patch is not split every 8 KiB waiting for ACK.
- Accepting a local TCP connection no longer blocks the listener while the QUIC stream opens.
